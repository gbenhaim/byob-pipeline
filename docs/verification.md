# Verification

Validated on 2026-10-28 with the Go 1.27 Cobra CLI, directly maintained catalog YAML,
and the remote Task generated by `make generate`.

`make check` passed:

- Go tests for filesystem validation, output staging, deterministic packaging,
  CLI restoration/publication, remote orchestration, the generator, and catalog
  wiring. Coverage includes empty/multiple build inputs, filename collisions,
  restore failures, malformed paths, symlinks, direct executable/argv handling,
  and failed publication without final results.
- Remote unit fixtures cover TLS OTP exchange with a controller CA, strict SSH
  host verification, quoting, and cancellation cleanup.
- ShellCheck for the retained VM worker and example scripts, Go vet and formatting.
- Admission-type validation against Tekton Pipelines 1.16.0 for all 3 Tasks and
  4 Pipelines, plus 5 example PipelineRuns.
- Generated remote Task drift checks.

A Go AST audit checked all 143 named function declarations, including tests,
helpers, methods, and entrypoints: every function has a name-leading documentation
comment. A full repository scan found no Python source or bytecode files; obsolete
Python ignore patterns and stale empty directories were removed.

`make image` built `localhost/byob-cli:devel` with the digest-pinned Red Hat
`hi/go:1.27` builder, verified as Go 1.27.3, and the pinned Konflux task-runner
runtime. The image includes the unmodified upstream artifact restoration helpers.

`make smoke` passed using the Go integration test, the built CLI image, disposable
local containers, and an anonymous HTTP registry. It exercised CLI commands and
the local build command from Task YAML as UID 1000, real
Trusted Artifact creation and restoration, deterministic output packaging, Syft
SPDX generation, OCI publication, and cosign SBOM attachment. Chained builds
restore the original checkout separately from prior outputs. Empty BUILD_ARTIFACTS
arrays and two real artifacts containing the same filename were exercised; their
contents remained separate under indexed input directories. Restored build
artifacts and the final archive were checked to exclude source files.

Remote source/input transfer, rootless Podman execution, output-only copy-back,
failure propagation, rejection of a symlinked out/ directory, and temporary-directory
cleanup were exercised with a local SSH transport fixture. Export also used a
read-only mount of the staged outputs, matching the Task's volume permissions.
The remote build read both indexed artifact inputs and verified their contents.
The temporary registry containers and networks were removed.

The smoke suite also built a native Go fixture in a `scratch` image containing
neither `/bin/sh` nor `/bin/bash`. Local and remote execution passed with an argv
array, both with no extra arguments and with spaces, quotes, leading dashes, and
shell operators as literal arguments. Its conflicting image CMD was not appended.
The fixture verified writable HOME and the local launcher's read-only mount.
Its temporary image was removed after the test.

The fixtures do not validate a real SSH server or controller deployment, cloud VM
allocation, or controller VM cleanup on completion/cancellation. OTP transport and
CLI cancellation behavior are covered by local fixtures. No live cluster was used,
and no catalog bundles were published. Chains signing, Source VSA, admission, and
release-policy integration remain platform validation work; these checks do not
establish SLSA certification. See [the platform prerequisites](../README.md#required-platform-integration)
and [the manual cluster test commands](../README.md#install-and-run) for the next
integration step.
