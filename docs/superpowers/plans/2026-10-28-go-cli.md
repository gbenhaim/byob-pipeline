# PoC Go CLI implementation plan

> **For agentic workers:** Use superpowers:executing-plans to implement and verify this migration. Independent filesystem and remote packages may be implemented in parallel under superpowers:dispatching-parallel-agents.

**Goal:** Move catalog inline scripts into a small Go 1.27 CLI and replace Python tests with Go tests.

**Architecture:** One `byob` binary exposes the existing trusted Task operations. Filesystem logic uses the Go standard library; restoration and publication reuse the existing Trusted Artifacts, ORAS, and Cosign tools. Remote orchestration uses Go and embeds the VM's Bash/Podman bootstrap. Task YAML calls CLI subcommands with arguments.

**Tech Stack:** Go 1.27, Red Hat Go builder, the pinned Konflux task-runner runtime, existing Trusted Artifacts helper scripts, rootless Podman, Tekton 1.16 validation.

**Spec:** The user's request to move inline scripts and tests to Go 1.27 for the PoC; existing contracts in `README.md` and the behavior tests at baseline `c8ca869`.

## Global constraints

- Preserve output-only intermediate uploads, indexed `BUILD_ARTIFACTS`, scalar `BUILD_ARTIFACT` results, and the private export volume.
- Preserve localhost execution, mixed platform matrices, rootless Podman, credential separation, path validation, and cleanup on failure.
- Keep directly authored Task/Pipeline YAML and the remote generator. Do not recreate a catalog renderer or deployment helper.
- Remove Python source/tests/dependencies and CI setup. Retain the small developer-image `/bin/sh` entry command and the embedded VM bootstrap because arbitrary developer images/VMs do not contain the CLI.
- Use one root Go module for the CLI, generator, and tests. Keep Tekton validation in its own Go 1.27 module to avoid adding Kubernetes dependencies to the CLI.
- Build a local PoC image; do not publish or deploy. Document replacing its local reference with a published digest for cluster use.

## Review focus

- Script paths and output symlinks must not escape their trees; retain tests for traversal, absolute links, FIFOs, and symlinked roots.
- Multiple inputs with colliding names must stay separate; verify invalid references and stop on restore failure.
- Publication failure must not emit final results; verify registry ports and malformed digests.
- Remote transfer must preserve relative symlinks, protect source, disable automatic mounts, and clean up failed builds.
- YAML arguments must invoke the correct command with parameter data intact; validate catalog wiring and execute the real image in smoke tests.
